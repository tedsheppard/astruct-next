## Worksection Overview

Volume 0 - Specification Index and Conventions forms part of the technical specification package for Riverside Towers - Mixed Use Development. It is intended to read as a disciplined NATSPEC-style worksection adapted to the commercial and site-specific conditions of this project.


The worksection is particularly sensitive to tender clarification and award because it influences façade performance, programme assumptions, scope interfaces, early procurement and therefore must be interpreted consistently with the contract bundle, relevant drawings, and later superintendent directions.
