## Priced per project

Astruct is billed **per project, per month**. Each project you run in Astruct, with its contract, documents and mail, counts once.

| Projects | Price per project, per month |
| --- | --- |
| First project | AU$199 |
| Projects 2–5 | AU$179 each |
| Projects 6–15 | AU$159 each |
| Projects 16–30 | AU$139 each |
| Projects 31 and over | AU$119 each |

## How the bands add up

Each project is charged at the rate for its band. The first project is always AU$199, and only the projects within a band get that band’s price.

For example, 8 projects cost:

- 1 × AU$199 = AU$199
- 4 × AU$179 = AU$716
- 3 × AU$159 = AU$477

That is **AU$1,392 a month**, an average of AU$174 per project. The [pricing page](/pricing) works out the total for any number of projects.

## Unlimited users

There is no charge per person. Everyone in your company account is included, on every project. See [Members and roles](/support/members-and-roles).

## Seeing your plan

**Settings > Billing** shows your plan.

All prices are in Australian dollars and exclude GST.
