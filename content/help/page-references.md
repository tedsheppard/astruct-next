Astruct shows where things came from, so you can check them before you rely on them.

## In answers

Each point in an answer carries a small reference. Hover or tap it to see the document, and the page for a document or the sender and date for an email. Open it to go straight to that page.

## In search results

Each result shows a page chip, such as **p 21**, and the words that matched. Emails show **Email** instead of a page.

## Where the page number comes from

It is the page of the file as it was uploaded or synced, counting from the first page of the PDF. It may differ from the number printed in the document’s own footer, for example when a contract has a cover page or unnumbered annexures.

## Quotes

When Astruct quotes a document as evidence, the quote is the document’s own words. If a quote can’t be found word for word in its source, Astruct doesn’t show it as evidence.

## If a reference looks wrong

Open the source and check. If the page doesn’t support the answer, tell Astruct in the chat. It will look again. And let us know at hello@astruct.io so we can improve it.
